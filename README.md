# glassblowing.tools

A community-maintained index of glassblowing and flameworking tools: who makes them, where to buy them, and reviews from people who use them. We don't sell anything.

Live site: https://glassblowing.tools/

It's a plain [Jekyll](https://jekyllrb.com/) site hosted on GitHub Pages. Tools, makers, and categories are Markdown files in `_tools/`, `_makers/`, and `_tool_categories/`. See [CONTRIBUTING.md](CONTRIBUTING.md) to add a tool or a review.
