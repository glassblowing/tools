# About the archive

{{ site.title }} is a catalog of the tools glassblowers and flameworkers use: jacks, shears, blowpipes, torches, and the rest. We list what exists, who makes it, and where to buy it.

**We don't sell anything.** "Visit seller" links go straight to the maker or shop, with no affiliate codes. Prices and stock change, so always check with the seller.

## How reviews work

This is a static site with no accounts and no database, so reviews go through GitHub:

1. On a tool's page, click **Write a review**. It opens a short form on GitHub (you'll need a free GitHub account).
2. A maintainer reads it and adds it to the tool's page, usually within a few days.
3. We'll publish the display name you give us, never your GitHub username unless you ask.

We skip reviews that are spam, written by the maker or seller, or not about the tool.

## Contributing

- **Missing a tool, or found a broken link?** [Suggest a tool](https://github.com/{{ site.repository }}/issues/new?template=add-tool.yml) or open an issue.
- **Comfortable with GitHub?** Every tool is a small text file in [`_tools/`](https://github.com/{{ site.repository }}/tree/main/_tools). Pull requests are welcome; see [CONTRIBUTING.md](https://github.com/{{ site.repository }}/blob/main/CONTRIBUTING.md).

Makers and shops: we're happy to fix wrong information about your products. Please open an issue.
