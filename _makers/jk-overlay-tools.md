A Swedish workshop making tools for the Swedish overlay technique: stainless jack handles and wooden inserts. It works with Fantlab (its Instagram links to fantlab.com), which sells the handles alongside its own overlay spades and finishing tools; Glasstrapes (Greg Lastrapes, Seattle) distributes the full set in the US.
