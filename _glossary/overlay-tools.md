## What it is

Swedish overlay tools are a set of adjustable stainless-steel handles that take interchangeable wooden inserts.{% include cite.html n=1 %} Fantlab, in Sweden, sells wooden overlay spades in three sizes, finishing tools that pair with them, and the stainless jack handles they fit, made by JK Overlay Tools.{% include cite.html n=2 %} Jakobsson also makes wooden overlay tongs to order.{% include cite.html n=3 %}

## How it's used

As the name says, they're for Swedish overlay work, sized to the overlay: Glasstrapes sells a medium set for overlays up to 6 inches wide and a large set for wider ones.{% include cite.html n=1 %}

## History

According to Glasstrapes, which distributes them in the US, the tools "were originally designed to execute the Swedish Overlay at Orrefors Glasbruk", and only one workshop, in Sweden, still makes them.{% include cite.html n=1 %} Its inserts are carved from pear wood.{% include cite.html n=1 %}
